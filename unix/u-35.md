## 개요

### 점검 내용

공유 서비스의 익명 접근 제한 설정 여부 점검

### 점검 목적

공유 서비스의 익명 접근을 제한하여 중요 정보의 노출을 방지하기 위함

### 보안 위협

공유 서비스의 익명 접근을 허용할 경우, 비인가자의 무단 접근으로 인한 중요 정보 탈취 또는 변조, 악성 코드 유포 등의 위험이 존재함

### 참고

> **참고**
>
> 익명 접속이 허용된 서버에 익명 사용자에 대해 쓰기 권한이 부여되어 있는 경우, 정상 파일에 대해 변조가 가능하므로 공개된 디렉터리 내 중요 데이터 여부를 주기적으로 확인해야 함

> **참고**
>
> 공유 서비스를 사용하지 않는 경우 양호 또는 N/A

## 점검 대상 및 판단 기준

### 대상

SOLARIS, LINUX, AIX, HP-UX 등

### 판단 기준

- **양호:** 공유 서비스에 대해 익명 접근을 제한한 경우
- **취약:** 공유 서비스에 대해 익명 접근을 허용한 경우

### 조치 방법

공유 서비스의 익명 접근 제한 설정

### 조치 시 영향

일반적인 경우 영향 없음

## 점검 및 조치 사례

### SOLARIS

**[기본 FTP]**

1. FTP 계정 확인

   ```sh command
   # cat /etc/passwd | grep ftp
   # cat /etc/passwd | grep anonymous
   ```

2. FTP 계정 제거

   ```sh command
   # userdel ftp
   # userdel anonymous
   ```

**[vsFTP]**

1. Anonymous FTP 활성화 여부 확인

   ```sh command
   # cat /etc/vsftpd/vsftpd.conf | grep anonymous_enable
   ```

2. Anonymous FTP 비활성화

   ```sh command
   # vi /etc/vsftpd/vsftpd.conf
   ```

   `anonymous_enable` 옵션을 `NO`로 수정

**[ProFTP]**

1. Anonymous FTP 활성화 여부 확인

   ```sh command
   # sed -n '/<Anonymous ~ftp>/,/<\/Anonymous>/p' /etc/proftpd/proftpd.conf
   ```

2. Anonymous FTP 비활성화

   ```sh command
   # vi /etc/proftpd/proftpd.conf
   ```

   `Anonymous` 필드 주석 처리

> **참고**
>
> `User`, `UserAlias` 옵션이 설정된 경우 익명 접근이 활성화되어 있는 상태

**[NFS]**

1. 익명 접근 활성화 여부 확인

   ```sh command
   # cat /etc/dfs/dfstab | grep anon
   ```

2. 익명 접근 비활성화

   ```sh command
   # vi /etc/dfs/dfstab
   ```

   `anon` 옵션을 `-1`로 수정

   ```text configuration
   share -F nfs -o rw, anon=-1 /home/example
   ```

3. NFS 서비스 재시작

   ```sh command
   # exportfs -u
   # exportfs -a
   ```

**[Samba]**

1. 익명 접근 허용 여부 확인

   ```sh command
   # cat /etc/samba/smb.conf | grep "guset ok"
   ```

2. 익명 사용자 접근 비활성화

   ```sh command
   # vi /etc/samba/smb.conf
   ```

   `guest ok` 옵션을 `no`로 수정

3. 변경된 설정 적용 및 재시작

   ```sh command
   # svcadm refresh samba
   ```
