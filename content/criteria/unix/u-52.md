## 개요

### 점검 내용

원격 접속 시 Telnet 프로토콜 사용 여부 점검

### 점검 목적

취약한 Telnet 프로토콜을 비활성화함으로써 계정 및 중요 정보 유출 방지하기 위함

### 보안 위협

원격 접속 시 Telnet 프로토콜을 사용할 경우, 데이터가 평문으로 전송되어 비인가자가 스니핑을 통해 계정 및 중요 정보를 외부로 유출할 위험이 존재함

### 참고

> **참고**
>
> **스니핑:** 컴퓨터 네트워크상에 흘러 다니는 트래픽을 도청하는 행위

## 점검 대상 및 판단 기준

### 대상

SOLARIS, LINUX, AIX, HP-UX 등

### 판단 기준

- **양호:** 원격 접속 시 Telnet 프로토콜을 비활성화하고 있는 경우
- **취약:** 원격 접속 시 Telnet 프로토콜을 사용하는 경우

### 조치 방법

Telnet, FTP 등 안전하지 않은 서비스 사용을 중지하고 SSH 설치 및 사용하도록 설정

### 조치 시 영향

일반적인 경우 영향 없음

## 점검 및 조치 사례

### SOLARIS

1. Telnet 서비스 활성화 여부 확인

   ```shell command
   # svcs -a | grep telnet
   ```

2. Telnet 서비스 비활성화

   ```shell command
   # svcadm disable svc:/network/telnet:default
   ```

3. SSH 서비스 실행

   ```shell command
   # svcadm enable ssh
   ```

### LINUX

**[inetd]**

1. `/etc/inetd.conf` 파일 내 Telnet 서비스 활성화 여부 확인

2. 해당 옵션이 허용된 경우 설정 제거

   ```text configuration
   telnet stream tcp nowait root /usr/sbin/in.telnetd
   ```

   주석 처리 혹은 명령어 줄 삭제

3. inetd 서비스 재시작

   ```shell command
   # service inetd restart
   ```

4. SSH 서비스 실행

   ```shell command
   # service sshd start
   ```

**[xinetd]**

1. `/etc/xinetd.d/telnet` 파일 내 Telnet 서비스 활성화 여부 확인

   ```shell command
   # cat /etc/xinetd.d/telnet
   ```

2. `/etc/xinetd.d/telnet` 파일의 `disable` 설정값 수정

   ```text configuration
   disable = yes
   ```

3. 설정 적용 및 서비스 재시작

   ```shell command
   # systemctl restart xinetd
   ```

4. SSH 서비스 실행

   ```shell command
   # systemctl start sshd
   ```

**[systemd]**

1. Telnet 서비스 활성화 여부 확인

   ```shell command
   # systemctl list-units --type=socket | grep telnet
   ```

2. Telnet 서비스 중지

   ```shell command
   # systemctl stop telnet.socket
   ```

3. Telnet 서비스 비활성화

   ```shell command
   # systemctl disable telnet.socket
   ```

4. SSH 서비스 실행

   ```shell command
   # systemctl start sshd
   ```

### AIX

1. `/etc/inetd.conf` 파일 내 Telnet 서비스 활성화 여부 확인

2. 해당 옵션이 허용된 경우 설정 제거

   ```text configuration
   telnet stream tcp6 nowait root /usr/sbin/telnetd telnetd –a
   ```

   주석 처리 혹은 명령어 줄 삭제

3. inetd 설정 적용

   ```shell command
   # refresh –s inetd
   ```

4. SSH 서비스 실행

   ```shell command
   # startsrc -s sshd
   ```

### HP-UX

1. `/etc/inetd.conf` 파일 내 Telnet 서비스 활성화 여부 확인

   ```shell command
   # cat /etc/inetd.conf | grep telnet
   ```

2. 해당 옵션이 허용된 경우 설정 제거

   ```text configuration
   # telnet stream tcp6 nowait root /usr/sbin/telnetd telnetd –a
   ```

   주석 처리 혹은 명령어 줄 삭제

3. inetd 설정 적용

   ```shell command
   # inetd –c
   ```

4. SSH 서비스 실행

   ```shell command
   # /sbin/init.d/secsh start
   ```
