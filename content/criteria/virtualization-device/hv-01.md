## 개요

### 점검 내용

웹 콘솔 및 사용자 Shell Session Timeout 설정 여부 점검

### 점검 목적

Session Timeout 기능을 구현하여 공격자가 만료되지 않은 세션 활용을 방지하기 위함

### 보안 위협

세션의 만료 기간을 정하지 않거나, 만료기한이 너무 길게 설정된 경우 악의적인 사용자가 만료되지 않은 세션을 활용하여 불법적인 접근을 시도할 수 있는 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

VMware ESXi, vCenter, XenServer, KVM, Nutanix

### 판단 기준

- **양호:** 웹 콘솔 및 사용자 Shell Session Timeout 설정이 600초(10분) 이하로 설정된 경우
- **취약:** 웹 콘솔 및 사용자 Shell Session Timeout 설정이 600초(10분)를 초과하여 설정된 경우

### 조치 방법

600초(10분) 동안 입력이 없을 경우 접속된 클라이언트 세션을 끊도록 설정

### 조치 시 영향

일반적인 경우 영향 없음

## 점검 및 조치 사례

### LINUX

**VMware ESXi, vCenter**

**웹 콘솔 Session Timeout 설정**

1. Web 콘솔 페이지 접속

   ```text literal
   https://<VMware ESXi IP>
   ```

2. 호스트 > 관리 > 시스템 > 고급 설정으로 이동

3. `UserVars.HostClientSessionTimeout` 설정이 600초(10분)로 설정되어 있는지 확인

4. 600초(10분) 이하로 설정되어 있지 않은 경우 [옵션 편집]을 클릭하여 아래와 같이 수정

   ```text configuration
   600
   ```

**XenServer, KVM**

**사용자 Shell Session Timeout 설정**

1. 호스트에 접속

2. `echo $TMOUT` 명령어를 이용하여 사용자 Shell Session Timeout 설정 확인

   ```shell command
   echo $TMOUT
   ```

   ```text output
   9000
   ```

3. Session Timeout 10분을 초과하는 경우 아래 두 라인 추가

   ```shell command
   vi /etc/profile
   ```

   ```shell configuration
   readonly TMOUT=600;
   export TMOUT
   ```

4. 변경된 설정 적용

   ```shell command
   source /etc/profile
   ```

**Nutanix**

**사용자 Shell Session Timeout 설정**

1. Controller VM에 접속하여 User Shell Session Timeout 설정 확인

   ```shell command
   sudo cat /etc/profile.d/os-security.sh
   ```

   ```shell output
   readonly TMOUT=9000 2> /dev/null || echo "TMOUT already set."
   readonly HISTFILE
   mesg n 2>/dev/null
   ```

2. `vi` 편집기를 이용하여 User Shell Session Timeout을 10분으로 설정

   ```shell command
   sudo vi /srv/salt/security/CVM/shellCVM.sls
   ```

   ```yaml configuration
   ossecuritycreate:
     file:
       - managed
       - name: /etc/profile.d/os-security.sh
       - mode: 644
       - user: root
       - group: root
       - contents: |
           readonly TMOUT=600 2> /dev/null || echo "TMOUT already set."
   ```

3. 변경된 설정 적용

   ```shell command
   sudo salt-call state.sls security/CVM/shellCVM
   ```

**SSH Idle Timeout 설정**

1. Controller VM에 접속하여 SSH Idle Timeout 설정 확인

   ```shell command
   sudo cat /etc/ssh/sshd_config | grep "ClientAliveInterval"
   ```

2. `vi` 편집기를 이용하여 SSH Idle Timeout을 10분으로 설정

   ```shell command
   sudo vi /srv/salt/security/CVM/sshd/sshdconfCVM
   ```

   ```text configuration
   ClientAliveInterval 600
   ```

3. 변경 설정 적용

   ```shell command
   sudo salt-call state.sls security/CVM/sshdCVM
   ```

**관리 웹 콘솔 Session Timeout 설정**

1. 관리 웹 콘솔 접속

   ```text literal
   https://<Nutanix 웹 콘솔 IP:9440>
   ```

2. Session Timeout 설정 적용. Settings > UI Settings > Security Setting의 SESSION TIMTOUT 설정을 10분으로 설정
