## 개요

### 점검 내용

NTP 설정을 통한 시간 동기화 여부 점검

### 점검 목적

시스템이 NTP를 통한 시간 동기화를 적용해 가상화 장비 침해, 장애 등의 위협 발생 시 원활한 로그 분석 수행이 가능하도록 하기 위함

### 보안 위협

시스템이 NTP를 통한 시간 동기화가 되지 않을 경우 가상화 장비 침해, 장애 등의 위협 발생 시 로그 분석을 통한 침입 경로 파악이 어려워 초기 대응 불가 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

VMware ESXi, vCenter, XenServer, KVM, Nutanix

### 판단 기준

- **양호:** NTP서버와 시간 동기화 설정을 적용한 경우
- **취약:** NTP 서버와 시간 동기화 설정을 적용하지 않은 경우

### 조치 방법

NTP 설정 및 시각 동기화 설정

### 조치 시 영향

일반적 경우 영향 없음

## 점검 및 조치 사례

### LINUX

**VMware ESXi**

1. Web 콘솔 페이지 접속

   ```text literal
   https://<VMware ESXi IP>
   ```

2. 호스트 > 관리 > 시스템 > 시간 및 날짜로 이동
3. NTP 설정 확인
4. NTP 서버가 설정되어 있지 않은 경우, [NTP 설정 편집]을 클릭하여 NTP 서버 정보 입력

**VMware vCenter**

1. vCenter Server 관리 페이지(`https://<주소>:5480/`) 접속 후, 다음 메뉴에 접근하여 확인(vCenter 버전에 따라, 메뉴 명칭은 달라질 수 있음)

   ```text literal
   # "시간" > "시간 동기화" > NTP 설정 여부를 확인
   ```

**KVM**

1. PHC 사용 여부 확인
2. 사용하지 않으면 활성화 적용

   ```shell command
   # echo ptp_kvm > /etc/modules-load.d/ptp_kvm.conf
   ```

3. `/dev/ptp0` 시계를 chrony 구성에 대한 참조로 추가 설정

   ```shell command
   # echo "refclock PHC /dev/ptp0 poll 2" >> /etc/chrony.conf
   ```

4. chrony 데몬 다시 시작

   ```shell command
   # systemctl restart chronyd
   ```

**XenServer**

1. XenServer 접속 > Network and Management Interface > Network Time (NTP) > Provide NTP Servers Manually > 별도 NTP 서버 지정 설정 적용

**Nutanix**

1. 웹 콘솔에 접속

   ```text literal
   https://<Nutanix 웹 콘솔 IP:9440>
   ```

2. Settings > NTP Servers 선택하여 NTP 서버가 설정되어 있는지 확인
3. 설정되어 있지 않은 경우 NTP 서버를 입력하고 Add 버튼을 클릭
4. Controller VM에 접속하여 타임존 설정

   ```shell command
   ncli cluster set-timezone timezone="Asia/Seoul“
   ```

5. Controller VM에 접속하여 Nutanix 호스트 타임존 설정

   ```shell command
   hostssh "date; mv /etc/localtime /etc/localtime.bak; ln -s /usr/share/zoneinfo/Asia/Seoul /etc/localtime; date“
   ```

> **참고**
>
> Nutanix를 처음 설치하면 타임존이 UTC로 설정되어 있어 실제 시간과 차이가 발생
