## 개요

### 점검 내용

NTP 및 시각 동기화 설정 여부 점검

### 점검 목적

안전하고 승인된 Windows 시간 서비스 또는 자체 구축한 NTP 서버와 동기화하여 인증 및 감사하기 위함

### 보안 위협

시스템 간 시각 동기화 미흡으로 보안 사고 및 장애 발생 시 초기 대응이 불가한 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

Windows NT, 2000, 2003, 2008, 2012, 2016, 2019, 2022

### 판단 기준

- **양호:** NTP 및 시각 동기화를 설정한 경우
- **취약:** NTP 및 시각 동기화를 설정하지 않은 경우

### 조치 방법

NTP 및 시각 동기화 설정

### 조치 시 영향

일반적인 경우 영향 없음

## 점검 및 조치 사례

### Solaris

**Windows 2000, 2003, 2008, 2012, 2016, 2019, 2022**

**인터넷 동기화 설정 시**

1. 제어판 > 시계 및 국가 > 날짜 및 시간 > 인터넷 시간 > 설정 변경 > 인터넷 시간 서버와 동기화
2. 신뢰할 수 있는 NTP 서버 입력 후 적용

**내부 NTP 서버 사용 시**

1. 시간 동기화 정보 확인 (Client)

   ```text command
   CMD > w32tm /dumpreg /subkey:parameters
   ```

   ```text output
   값 이름                    값 종류                 값 데이터
   NtpServer                  REG_SZ                  time.windows.com,0x9
   ServiceDll                 REG_EXPAND_SZ           %systemroot%\system32\w32time.dll
   ServiceDllUnloadOnStop     REG_DWORD               1
   ServiceMain                REG_SZ                  SvchostEntry_W32Time
   Type                       REG_SZ                  NTP
   ```

2. 내부 NTP서버로 시간동기화 설정 (Client)

   ```text command
   (설정) CMD > w32tm /config /syncfromflags:manual /manualpeerlist:{NTP서버 IP or 도메인} /update
   (적용 확인) CMD > w32tm /dumpreg /subkey:parameters
   ```

   ```text output
   값 이름                    값 종류                 값 데이터
   NtpServer                  REG_SZ                  192.168.238.128,0x9
   ServiceDll                 REG_EXPAND_SZ           %systemroot%\system32\w32time.dll
   ServiceDllUnloadOnStop     REG_DWORD               1
   ServiceMain                REG_SZ                  SvchostEntry_W32Time
   Type                       REG_SZ                  NTP
   ```

> **참고**
>
> Client에서 동기화 설정 후 `SpecialPollInterval` `MaxPosPhaseCorrection` 설정에 따라 주기적으로 자동으로 동기화가 적용되지만 NTP Server에서 다음 명령어로 즉시 적용 가능함.

   ```text command
   CMD > w32tm /resync
   ```

   ```text output
   로컬 컴퓨터에 다시 동기화 명령을 보내는 중
   명령이 성공적으로 완료되었습니다.
   ```

3. 동기화 시간차 확인

   ```text command
   CMD > w32tm /stripchart /dataonly /computer:{NTP서버 IP or 도메인}
   ```

   ```text output
   192.168.238.128[192.168.238.128:123] 추적 중
   현재 시간은 2024-12-02 오후 6:56:30입니다.
   18:56:30, +00.0425597s
   18:56:32, +00.0426009s
   18:56:34, +00.0425101s
   18:56:36, +00.0425450s
   18:56:38, +00.0425516s
   18:56:40, +00.0425858s
   ```
